# My Expensia

A private Flutter expense and portfolio tracker. Inflow adds to your portfolio; outflow deducts from it. All data stays on the device.

## Run on an Android emulator

1. Install the Flutter SDK and Android Studio, including an Android emulator.
2. From this folder, run `flutter create --platforms=android .` to generate the Android host project.
3. Run `flutter pub get`.
4. Start an Android emulator from Android Studio, then run `flutter run`.

## Run on an iPhone

iPhone Simulator requires a Mac with Xcode. On macOS, generate the iOS host project with `flutter create --platforms=ios .`, then run `flutter run` with a simulator open.
